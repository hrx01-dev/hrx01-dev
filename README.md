### 01 / A little about the builder

I'm **Jayam**, a developer from **India** working across full-stack applications, applied AI, and open source. I like taking an idea all the way from its first interface to the APIs and systems behind it.

Right now, I'm building **Helixity** to help teams keep up with API changes, exploring useful AI through healthcare projects, and creating web experiences through **Servio**. Hackathons are where I test ideas quickly; open source is where I learn to make them better.

**I care about:** interfaces that feel considered, software that solves a real problem, and learning by shipping.
